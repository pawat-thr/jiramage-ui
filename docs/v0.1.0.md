# v0.1.0 — Baseline (initial commit)

> What the app contained at the first push (`feat:init project v0.1`).

## Pages (5–7 depending on mode)

| Page | Notes |
|---|---|
| **Dashboard** | Stat tiles (Team/To Do/In Progress/Done/My open), stacked tasks-per-member chart (me included), work-type & status breakdowns, member drill-through to Team |
| **My Tasks** | Own issues grouped by work type; search, type & status filters; priority colors |
| **Team** | Team issues; member/type/status filters, search; transition (`move`) & reassign (`assign`) row actions |
| **PR Review** *(team mode)* | Post a GitHub PR (main link + extra links + Jira spec), assign reviewers from env, reviewer/owner set status, live comments — Firestore-backed |
| **Settings** | Light/dark/system theme switcher; Account (change password) in team mode; read-only `.env` view |
| **Login** *(team mode)* | Firebase email/password; team-allowlist (JIRA_EMAIL + TEAM_EMAILS); first-time "set password" flow with strength rules (≥8, upper, number, special); show-password checkbox & eye toggles |

## Platform / UX

- **Two modes**: individual (no Firebase → no login, PR hidden) and team (Firebase login + PR board)
- Red accent theme, light/dark/system (saved per browser), no-flash pre-paint script
- Collapsible sidebar (icon rail) + mobile drawer; full-width responsive layout
- Work-type grouping with colored chips; Jira-style status colors; green kept for "done/success"
- Animations: page enter, modal pop, toast rise, dropdown pop, chart width transitions
- Refresh button with busy state + success toast; 5-min auto-refresh; paginated fetch of all issues
- Keyboard shortcuts 1–N, `h` = active-only toggle
- Logo + favicon; MIT LICENSE; sidebar copyright footer

## Data / integration

- Jira via Vite dev-server proxy (Basic auth injected server-side; XSRF headers stripped)
- Firebase: Auth (email/password) + Firestore (`prs` collection with comments subcollection)
- Firestore security rules for PRs (owner edit/delete; reviewer status-only) — published via console

## Engineering

- React 18 + Vite 5 + Tailwind v4 (`@theme` tokens), feature-based folder structure
- 43 unit tests (Vitest + React Testing Library): utils, aggregation, components, hooks
- Page state via a single `tab` (no URL routing yet)
