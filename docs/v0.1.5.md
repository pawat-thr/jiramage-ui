# v0.1.5 — What's new since v0.1.0

> Everything added between the initial commit and this version (this push).

## 🆕 New pages

### Story List (`/story-list`)
- All Story-type cards; **Release** filter (custom field `customfield_10127`, configurable via `JIRA_RELEASE_FIELD`), **Status** filter with an **"Active"** default (hides Done / DROPPED-CANCELLED), search, sorted by key desc
- **"Set as default" release** button — saved per user (Firestore in team mode, localStorage in individual); Story List opens pre-filtered to it
- **Story detail sub-page**: full Jira-like view — description & comments rendered from Atlassian Document Format (own ADF renderer: lists, tables, code, mentions, panels…), meta grid, labels/release chips, **subtasks with owners**, Open-in-Jira

### Delivery Tracking (beta) (`/delivery`)
- PM view of a Release: **release summary card** — overall % + points done, story status counts, per-role **FE / BE / QA** rollups with stacked progress bars, **Test Case design tracking** (the `[QA] Test case` subtask: % designed, points), warning for stories without role subtasks
- **Excel-style table** (horizontal scroll): key · name · status · progress % · per-role cells (`done/total pts · done/total tasks` + mini stacked bar) · Test Case state
- Release + Status filters, search; stories sorted **least-done-first**
- Roles detected from `[FE]`/`[BE]`/`[QA]` subtask prefixes; points from `customfield_10016` (configurable via `JIRA_POINT_FIELD`); subtasks bulk-fetched per release (chunked `parent in (...)`)
- Story detail reused from Story List (`/delivery/DX-123`)

### Team Board (`/team-board`, team mode)
- **Labels**: create / **rename (cascades to all tasks atomically)** / delete (only when unused), color-coded
- **Tasks**: ref-card toggle (search & link a Story by key/title, or internal work with a name), 0..n assigned users, label (required), ENV 1-2-3, sprint start date, detail text
- Board **grouped by label** (sorted by name); cards show key/INTERNAL, name, user avatars, ENV + sprint, status stripe
- **Task detail** with clickable statuses (To Do / In Progress / Waiting / Wait Migrate / Done); linked story renders the full Jira detail below; owner-only edit/delete
- Firestore-backed (`labels`, `tasks`) with matching security rules

## 📈 Dashboard

- New **"Active subtasks · points"** panel — per member: active subtask count + summed story points, with total

## 🧭 Routing

- **Real URLs for every page** (react-router): `/`, `/my-tasks`, `/team-task`, `/story-list`, `/delivery`, `/team-board`, `/pr-review`, `/settings`
- **Detail deep links**: `/story-list/DX-123`, `/delivery/DX-123`, `/team-board/<id>`, `/pr-review/<id>` — browser back/forward closes details naturally

## 🔧 Improvements & fixes

- **Team** renamed to **Team Task**; its member filter now clears when leaving the page (dashboard drill-through still works)
- **My Tasks / Team Task**: subtasks show their **parent story** (`↳ DX-123 …`) linked to Jira
- **PR Review polish**: wider New-PR modal, multiple extra PR links (add/remove rows), colored status stripes, chat-style comment box (avatars, ⌘/Ctrl+Enter), nice **delete confirmation dialog** (replaces `window.confirm`), fixed Edit-from-detail doing nothing + stray create popup after delete
- **UI density**: whole app at **80% zoom** filling the full display; popups/toasts stay 100%
- **Bug fix**: retained animation transforms broke `position: fixed` — modals now always center on the screen (fill-mode `backwards`)
- Light-theme borders thickened (1.5px) for visibility; new logo (`logo2.png` → optimized `public/` copies)
- Settings: removed the release picker (moved to Story List where the data lives)

## 🔐 Firestore rules (republish required)

`firestore.rules` now covers: `userPrefs` (owner-only), `labels` (create/rename/delete by members), `tasks` (owner edits; anyone moves status; label renames cascade), plus the existing `prs` rules.
