# v0.1.6 — What's new since v0.1.5

> UX-focused release: Delivery QA view, big-team support, and redesigned popups, login, and settings.

## 📦 Delivery Tracking (beta)

- **New QA view** (toggle next to Delivery view): per-story breakdown of the **10 QA subtask categories** — QA Total, Test Case, Test Review, Test Data on SIT, Test Execute SIT, Test Data on UAT & Regression, Support UAT, Support Regression, Support PVT, Review Task
  - Excel-style table: **Key · Name · Status frozen**, category columns slide horizontally; each cell shows state pill + `done/total pts`
  - **QA summary card**: overall QA % + all categories with stacked progress bars
  - **QA pair filter** (both required): category type × state (To Do / In Progress / Done)
- **Test Case removed** from the Delivery view table and release summary (it lives in the QA view now)

## 🧑‍🤝‍🧑 Team Board

- **New field: Target date** — shown on cards (`⇥ date`, red when overdue) and in task detail (`overdue` flag); no Firestore rule change needed
- **New Task / Edit Task popup redesigned**: radio-style type cards ("Link a Jira story" / "Internal work" with descriptions), grouped sections (Organize / Schedule / Detail) with dividers, required-field marks, unified footer (Cancel + Create together — the stray bottom Cancel is gone via a new `hideFooter` option on ModalShell)

## 👥 Member picker (scales to 20+ users)

New shared `MemberPicker` used in **Team Board task popup (Users)** and **PR popup (Reviewers)**:
- Picked members float to the top as removable chips with a count + "clear all"
- **Filter box appears automatically at 8+ members**; full list scrolls in a fixed-height box so the popup never grows
- Selected members show a ✓; avatars everywhere

## 🔐 Login

- **Full redesign**: logo + name above the card with a soft accent glow; clearer tabs ("Sign in" / "First time here") with per-mode hints; cross-links between modes
- **Live password rule checklist** in first-time mode — each rule flips green as you type (8+ chars, uppercase, number, special, passwords match); submit disabled until all pass
- Rules refactored into shared `PASSWORD_CHECKS` (`src/utils/password.js`) — same validation messages everywhere
- **`/login` is a real route**: signed-out users are redirected to it from any URL; **visiting `/login` while signed in (or in individual mode) redirects to home**

## ⚙️ Settings

- Page split into two labeled zones:
  - **"Your settings"** — Display + Account, badged **Editable**
  - **"Fixed configuration"** — Connection / Team / Preferences, badged 🔒 **Fixed · .env**, with a note that changes require editing `.env` + restart
- Fixed values render as clean label/value rows instead of fake disabled inputs; the mock "Save changes" button is gone
- New **Mode** row shows "Team (Firebase connected)" vs "Individual (no Firebase env)"

## 🎨 Theme & Dashboard

- **Dark theme background is now a gray gradient** (`#21242c → #16181e → #101217`, fixed while scrolling) instead of flat near-black; `--c-bg` re-tuned to the midpoint so the blurred top bar and table stripes blend in
- **Dashboard "Active subtasks · points"**: workload **heat gradient** — bars and point totals shift from slate toward red for the most-loaded member ("redder = heavier load")

## 📊 Delivery export (.xlsx)

- **"⇩ Export .xlsx" button** on the Delivery page — downloads the current filtered tables as one workbook:
  - **Delivery sheet**: two-row grouped header — Key/Name/Status + **FE / BE / QA** groups, each split into Total · In Progress · Done (numeric points, pivot-friendly)
  - **QA Info sheet**: points only (`done/total`) per QA category + a **QA Subtasks (Done/Total)** count column
- Library: **SheetJS 0.20.3** from the official SheetJS CDN (npm's 0.18.5 has known advisories); **lazy-loaded** into its own chunk, so page loads pay nothing
- Filename `delivery-<release>-<date>.xlsx`, Windows-unsafe characters cleaned; Thai text exports correctly

## 🔔 Notification inbox (team mode)

- **Bell icon in the top bar** with a live unread badge — an in-app inbox, **not** push/FCM: users see it when they open the app
- Three event types, all addressed to the relevant person (never yourself):
  - **Assigned to review** — PR created or edited to add you as reviewer ("X assigned you to review Y"); no re-notify on unrelated edits
  - **Status changed** — someone changes the status of *your* PR ("X changed your PR status to Approved")
  - **New comment** — someone comments on *your* PR ("X commented on your PR")
- Dropdown inbox: unread highlighted with a dot, click → marks read + jumps to the PR, **Mark all read**, "View all in Inbox →" footer
- **Inbox page** (`/inbox`, in the sidebar): full notification history with All/Unread tabs, Mark all read, and per-item delete (✕ on hover)
- **Notification sound** (Messenger-style two-tone ping, synthesized — no audio asset):
  - plays when a **new** notification arrives (id-tracked, no re-ping on reconnect)
  - plays once on **load/refresh** if unread items exist (browsers may defer it to the first click — handled automatically)
  - **softer reminder every `REFRESH_INTERVAL`** (same env, default 5m) while unread items remain
  - **On/Off toggle** in Settings → Display (per browser); Off also silences everything
- **Tab title badge** — `(3) jiramage` — always works, even when sound is blocked or muted
- New Firestore collection `notifications`; writes are best-effort (a failed notification never blocks the PR save)

## 🔐 Firestore rules (republish required)

New `notifications` block: sender creates entries addressed to teammates only; **only the recipient can read**, can update just the `read` flag (to true), and can delete their own entries.

- Version **0.1.6** everywhere (package.json, `APP_VERSION`, proxy User-Agent)
- New dependency: `xlsx` (pinned as a CDN tarball URL in package.json — SheetJS's official install method)
